# Lucide

사용자가 아이콘 이미지, 스크린샷, 또는 "공유 아이콘 같은 거" 식의 텍스트 설명을 주면, 그에 해당하는 **Lucide 아이콘명**을 찾아서 알려준다. **파일은 수정하지 않는다. 채팅 답변만 한다.**

기준 버전: 이 프로젝트에 설치된 `lucide-react` 버전(`package.json` 참고), 확인이 어려우면 Lucide 최신 버전 기준으로 판단한다.

## 1단계 — 입력 파악

- 이미지가 주어지면 아이콘의 형태(선/도형 구성, 획, 방향, 채움 여부)를 구체적으로 관찰한다.
- 텍스트 설명이면 의미(공유, 저장, 알림 등)와 형태 단서를 함께 파악한다.
- Lucide는 아이콘 두 개가 비슷한 이름으로 갈리는 경우가 많다(예: `Share` = 상자+위로 나가는 화살표, `Share2` = 노드 3개 연결). 형태를 정확히 구분해서 매칭한다.

## 2단계 — 출력

- **정확히 일치하는 아이콘이 있으면**: 그 아이콘 하나를 제시하고, 왜 이게 맞는지 한 줄로 설명한다.
- **정확히 일치하는 게 없으면**: "정확히 같은 건 없다"고 먼저 밝히고, 형태가 가까운 순으로 후보 2~4개를 제시한다. 각 후보마다 어떤 점이 같고 어떤 점이 다른지 한 줄로 적는다.
- 아이콘명은 **`Icon` 접미사 표기만** 준다: `Share2Icon`, `CircleHelpIcon` 등. PascalCase 별칭·kebab-case·import 구문은 넣지 않는다.

## 주의사항

- 파일을 Edit/Write 로 수정하지 않는다. Read, Grep, Glob, Bash(조회) 만 사용한다.
- 후보를 무의미하게 늘리지 않는다. 형태가 실제로 가까운 것만 추린다.
